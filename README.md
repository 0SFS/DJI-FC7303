# DJI FC7303

Local camera model mod for DJI-Mini2. Owns resolution, diagonal field of view, lens, exposure and JPEG metadata. Depends on `0SFS/drone-camera` for shared WebGPU capture; the airframe declares gimbal mount limits. Runtime code is not loaded on installation.

No repository has been created or published.

Topics: `0sfs-mod` and `0sfs-component-mod`. [Modding guide](https://github.com/0SFS/docs/blob/main/modding.md) describes discovery and installation.
